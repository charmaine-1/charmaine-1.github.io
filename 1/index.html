2. Numerical Approach (Handwritten Solutions)

The idea is to have alternating calculation for the different constant values. In the case of linear function, there are two constants m & c. As shown below, we will first calculate m and then use that calculated m value to calculate c. Using that calculated c value, we are going to use it to calculate for the m value again. These iterations continue until these m & c values converge.

The same idea could be applied on the parabola function. In the case of parabola function, there are three constants a, b & c. We could do the same thing to calculate these values till convergence.
